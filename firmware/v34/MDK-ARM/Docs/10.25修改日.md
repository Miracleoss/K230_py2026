STM32F405 时钟树（HSE → 168 MHz）与 TIM5 1 μs 硬件时基修改报告

本次修改完成了 STM32CubeMX 工程配置与 HAL / 用户层固件代码的同步升级，将系统主时钟由内部 RC 振荡器（HSI 16 MHz → 84 MHz）切换为外部高速晶振满频运行（HSE 24 MHz → 168 MHz），同步修正 TIM1 舵机 PWM 预分频系数，并将系统时基 TIM5 升级为 1 μs 硬件计数分辨率 + 无锁防跨拍微秒读取链路。

IMPORTANT

本次修改严格遵循范围边界：未改动闭环控制采样分频（保持 200 Hz / 5 ms 轮询与 BMI088 寄存器 ODR 配置）及 USART1 波特率（保持 115200 bps 与遥测发送逻辑）。

3.2 驱动层：1 μs 无锁单调时基封装
drv_timebase.h（第 25-39 行）与 drv_timebase.cpp（第 25-92 行）
Class_Timebase::Start：在调用 HAL_TIM_Base_Start_IT(timer_) 前清零 uptime_ms_ = 0U、CNT = 0U，并显式清除 HAL_TIM_Base_Init 触发 UG 更新事件残留的 TIM_FLAG_UPDATE 标志，防止启动瞬间误触发首拍溢出中断。
Class_Timebase::NowUs：在不引入关中断（__disable_irq）或 std::atomic 的前提下，通过双读重试 + TIM_FLAG_UPDATE (UIF) 跨拍补偿合成 64 位微秒时间戳：
依次读取 ms_first → cnt_first → update_pending (UIF) → cnt_second → ms_second；
若读取期间被 TIM5 中断抢占并递增了 uptime_ms_，则 ms_first != ms_second 自动循环重读；
若硬件计数器刚完成 999 → 0 翻转并置位 UIF，而中断尚未响应（update_pending == true），则采用翻转后的 cnt_second 并对毫秒计数执行 (ms_first + 1) * 1000 + cnt_second 补偿；反之采用翻转前同纪元的 ms_first * 1000 + cnt_first，严格消除跨毫秒边界出现 -1000 μs 回退或 +1000 μs 跳变的竞态窗口。
3.3 公共数据、设备转换、闭环控制器与任务调度层

imu_data.h — ImuData

新增 uint64_t sample_timestamp_us 字段（默认构造初始化为 0ULL），同时保留原有 sample_timestamp_ms，保证上层协议及旧测试用例 100% 兼容。

dev_bmi088.h（第 44-55 行）与 dev_bmi088.cpp（第 43-79 行）

新增四参数重载 Bmi088RawSampleToImuData，在原始计数值转 SI 单位并变换至机体坐标系时同步写入 sample_timestamp_ms 与 sample_timestamp_us；原三参数版本自动委托折算 sample_timestamp_ms * 1000ULL。

alg_closed_loop_controller.h（第 106-107 行）与 alg_closed_loop_controller.cpp（第 20-27、331-340、437 行）

将控制器内部样本门控状态由 last_sample_timestamp_ms_ 升级为 uint64_t last_sample_timestamp_us_。
新增 ResolveSampleTimestampUs（优先取 imu.sample_timestamp_us，为 0 时自动回退 sample_timestamp_ms * 1000ULL），使新样本唯一性门控与时间戳单调不回退校验均具备 1 μs 分辨率。

task_bridge.cpp — Task_Init 与 Task_Loop

主循环节拍与采样率保持不变：仍以 NowMs() 进行 1 ms 节拍门控，按 bmi088_poll_divider >= 5U（200 Hz）读取 BMI088。
全链路接入 1 μs 硬件时间戳：
BMI088 采样完成即刻调用 system_timebase.NowUs() 打上微秒与毫秒时间戳（StoreBmi088BodyImuData 同步保存 sample_timestamp_us）；
上位机指令超时门控（last_host_command_us）与 IMU 数据保鲜门控（sample_timestamp_us）统一按微秒差值精确判定；
IMU 恒温加热器更新周期与离散积分 heater_dt_s 改由 NowUs() 真实微秒间隔（× 1.0e-6f）驱动；
飞控闭环解算周期 dt_s 改由相邻两帧有效控制样本的硬件微秒差 (sample_timestamp_us - last_control_timestamp_us) * 1.0e-6f 计算，彻底消除毫秒截断造成的周期量化噪声。
