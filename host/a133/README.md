# 上位机 · A133

这里只放**你们自己写的那层**：视觉、制导解算、串口对接、状态机。

A133 的 BSP、内核、buildroot 不进这个仓库（见 `docs/build.md` 里的硬约束）。

## 目录约定（建议）

```
host/a133/
├─ src/            # 应用层源码
├─ scripts/        # 拉 SDK、交叉编译、部署到板子的脚本
└─ README.md       # 本文件
```

## 和固件的接口

只认 `docs/protocol.md`。

⚠️ 目前两版固件的 IMU 帧长度不同（V33 = 29 字节，V34 = 31 字节），帧头都是 `55 AA` 且没有版本字段。上位机必须先确认对端烧的是哪一版，解析器长度不能混用。
